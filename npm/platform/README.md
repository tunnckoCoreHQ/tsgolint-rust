# @tsgolint-rust/{target}

The `{target}` binary of [tsgolint-rust](https://github.com/tunnckoCoreHQ/tsgolint-rust), a Rust port of tsgolint for oxlint's `--type-aware` and `--type-check`.

Install [`tsgolint-rust`](https://www.npmjs.com/package/tsgolint-rust) instead: it depends on this package for this platform and runs its binary.
